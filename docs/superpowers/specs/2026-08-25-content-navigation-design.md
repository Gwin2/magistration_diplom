# Навигация по смысловым блокам страницы

## Цель

Дополнить существующую навигацию по этапам обучения компактным плавающим меню. Пользователь должен быстро переходить к любому смысловому блоку текущей секции без постоянного поиска по экрану.

## Группы блоков

- Обзор: Сводка проекта, Живые метрики, Дашборды.
- Данные: Загрузка данных, Библиотека датасетов.
- Студия: Конфиги экспериментов, Редактор конфига, Библиотека архитектур, Конструктор архитектуры, Редактор архитектуры, Панель запуска.
- Эксперименты: Реестр экспериментов, Сравнение запусков, Администрирование эксперимента, Задачи, Консоль задачи, TensorBoard.
- Публикация: Реестр TorchServe, Проверка инференса.
- Ресурсы: Управление ресурсами, Потребление контейнеров и процессов.

## UI

- Левая панель этапов остаётся основной навигацией верхнего уровня.
- Справа фиксируется кнопка `Содержание`.
- Кнопка открывает popover с блоками активной секции.
- Группы в popover можно сворачивать и разворачивать.
- На мобильных popover открывается поверх контента и закрывается после перехода.
- Текущий блок подсвечивается.
- Все интерактивные элементы доступны с клавиатуры и имеют видимый focus.

## Поведение

- Список пунктов строится из заголовков и секций DOM, чтобы не дублировать разметку в JavaScript.
- Каждый пункт ведёт к соответствующей панели через `scrollIntoView`.
- `IntersectionObserver` обновляет активный пункт во время прокрутки.
- При смене этапа список меню пересобирается для новой `.tab-pane`.
- Если заголовок или блок отсутствует, он не попадает в меню; приложение продолжает работать.
- Drag-and-drop порядка и постоянное скрытие блоков не входят в первую версию.

## Проверка

- Проверить переходы для всех шести секций.
- Проверить открытие/закрытие мышью, клавиатурой и кликом вне меню.
- Проверить мобильную ширину и отсутствие горизонтального переполнения.
- Проверить, что переключение этапов и существующее меню не ломаются.
